## AI Telegram Bot
## О проекте
Telegram-бот с интеграцией API нейросети, который генерирует ответы на сообщения пользователей.
## Возможности
Обработка текстовых сообщений и фото пользователей
Генерация ответов через API нейросети
Обработка ошибок при обращении к API
## Технологии
Python
aiogram
API нейросети
## Установка
Клонируйте репозиторий.
Установите зависимости:
pip install -r requirements.txt

Создайте файл .env и укажите необходимые API-ключи и токены.
Запустите приложение:
python main.py

## Безопасность
Не публикуйте API-ключи и токены. Файл .env должен оставаться локальным.
